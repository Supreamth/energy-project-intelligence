Capacity

แกนฟิลด์ค่าที่รับ
ขอบเขตการนับscopeproject / phase / unknown
สถานะของตัวเลขcapacity_statusplanned / operating / unknown
ชนิดกำลังmetricsolar_dc, solar_ac, export_limit, dc_it_load, dc_facility_power, contracted_power
หน่วยMWBESS แยก metric ภายหลัง ห้ามยัดเข้า value_mw

predicate: capacity.{metric}.{scope}.{capacity_status} เช่น capacity.dc_it_load.phase.planned

ห้ามรวม MWp กับ MWac, IT load กับ facility power, project total กับ phase total และห้ามสร้างเฟสจากยอดรวม

ใบอนุญาต

สถานะ regulatory ต้องมี license_kind = erc_generation | boi_promotion | other และ license_external_key ได้

field key: regulatory.erc.generation และ regulatory.boi.promotion ห้ามทับกัน

Review history

evidence.review_status เป็นค่าปัจจุบัน ทุกการเปลี่ยนสถานะต้องแทรกแถวใน evidence_review_events ใน transaction เดียว ห้ามแก้ประวัติย้อนหลัง

Publication

canonical มี publication_class = internal | external · MVP อ่านเฉพาะ internal · rights unknown/internal_only ห้ามเป็น external · ยังไม่เปิด public API

Canonical invalidation

ถ้า evidence ถูก reject/superseded หรือสิทธิแหล่งข้อมูลเปลี่ยน ให้ปิดแถว canonical เดิมด้วย superseded_at + invalidation_reason ห้ามระบบเลือกค่าใหม่เอง คนหรือกฎที่อนุมัติแล้วต้องเลือกใหม่

Fetch failure

fetch_events.raw_record_id เป็น NULL ได้เมื่อดึงไม่สำเร็จ เก็บ http_status และ error_class ห้ามตีความ HTTP 404 ว่าโครงการยกเลิก

Predicate registry

ingestion ปฏิเสธ predicate ที่ไม่อยู่ใน registry 0.2.0 canonical ปฏิเสธถ้า field_key ไม่ตรง registry

Ingestion contract 0.2

ต้องมี schema_version=0.2, source_code, external_key, extractor_version, fetched_at, payload sha256/uri

subject_external_key หาจาก source_entity_links ถ้าไม่เจอ เก็บ evidence ที่ subject เป็น NULL ได้ แต่ accept/canonical ไม่ได้จนกว่าจะจับคู่

ตัวอย่างไม่ผ่าน

  • ใช้ basis แบบ v0.1 โดยไม่มี scope / capacity_status
  • เก็บ 0 แทนค่าไม่ทราบ
  • predicate ระดับ phase แต่ subject เป็น project
  • เลือก evidence ที่ pending เป็น canonical
  • rights unknown แล้ว publish external
  • HTTP 404 = โครงการยกเลิก
